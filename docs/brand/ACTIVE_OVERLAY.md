# Active Crewmori brand overlay

The retained original brand package is in `original/`. The implemented product follows the warm canvas, forest identity, local Inter/Newsreader typography and generous rounded panels specified in the primary Home/Team anchors.

Runtime tokens and font declarations: `src/app/globals.css`. Runtime assets: `public/assets/brand`, `public/assets/characters`, `public/assets/fonts`, `public/assets/demo`. The canonical owner UI primitives are in `src/components/ui.tsx`; domain styles consume the same variables.

Root `DESIGN.md` and `UX-CONTRACT.md` are the maintained design/interaction overlay. Original specification copies remain under `docs/`. Original brand guide DejaVu examples do not override the explicitly approved Inter/Newsreader product typography. All six supplied character identities and the studio map remain local assets.
