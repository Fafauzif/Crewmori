# Principal frontend exploration pack

Prepared 16 October 2026. This pack asks Google Stitch for a visual frontend prototype. All people, companies, conversations, activity and monetary examples are fictional. No backend, real agents, live voice, posting or payments are required.

## Start here

1. Unzip this archive.
2. Start a web-app design in Stitch. Paste the complete contents of `01_MASTER_PROMPT.md`.
3. Add `DESIGN.md` as design-system context using the input/import options available in your Stitch session. If that option is absent, paste its text into the conversation.
4. Generate **Screen A: Business workspace first**. Judge its composition, characters and agent presence before generating the other screens.
5. Add `02_SCREENS.md`, `03_AGENTS_AND_INTERACTIONS.md` and `04_DEMO_DATA.json` as supporting context, or paste the relevant sections as you iterate. The master prompt already contains enough context to start.
6. Ask Stitch to continue with Screens B–E, using Screen A's exact visual system. Use `05_REFINEMENT_PROMPTS.md` to steer specific problems.

The ZIP is a transport package. Whole-ZIP ingestion was not verified. Unzip it and provide the individual files or their text. Google describes text, image and code context plus DESIGN.md import/export; available controls may differ by session.

## Files

| File | Purpose |
|---|---|
| `01_MASTER_PROMPT.md` | Paste-ready initial generation prompt |
| `DESIGN.md` | Visual system, layout, typography, colors and accessibility |
| `02_SCREENS.md` | Five connected screens and a reusable agent inspector |
| `03_AGENTS_AND_INTERACTIONS.md` | Six characters, cursors, task handoffs and prototype behavior |
| `04_DEMO_DATA.json` | Consistent fictional content and checked example arithmetic |
| `05_REFINEMENT_PROMPTS.md` | Short prompts for iteration and final review |

## What to assess

Can you immediately understand the business, see all six specialists, identify what they are working on and find the decision needing owner input? Does the screen feel suitable for an independent professional? Does it make delegation appealing? Those are the goals of this visual exploration.

Stitch may generate static screens before interactions. Treat voice waves, agent cursors and financial progression as illustrated prototype states until explicitly implemented. No service should be connected for this exploration.

## Reference notes

Google's [18 March 2026 Stitch announcement](https://blog.google/innovation-and-ai/models-and-research/google-labs/stitch-ai-ui-design/) describes natural-language design, multimodal canvas context, DESIGN.md and connected prototypes. Checked 16 October 2026. The public [prompting](https://stitch.withgoogle.com/docs/learn/prompting/) and [design-system](https://stitch.withgoogle.com/docs/design-md/) routes returned application shells during text retrieval, so this pack does not assume an exact current upload menu or ZIP support.

The visual direction is a custom proposal for Principal. It applies basic accessibility/navigation principles, rather than treating a generic enterprise-dashboard template as the product brief.
